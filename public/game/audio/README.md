# Office Groove soundtrack

`office-groove.wav` is an original procedurally synthesized instrumental track created for Office Rhythm Manager. It is generated by `scripts/generate-office-groove.mjs` with no third-party samples, recordings, or musical files.

- Tempo: 110 BPM, 4/4
- Duration: 120 seconds (55 bars / 220 beats)
- Format: mono PCM WAV, 22,050 Hz, 16-bit
- Rights: original project asset; may be redistributed and played as part of this project without third-party attribution requirements.
- Rebuild: `node scripts/generate-office-groove.mjs`

The rhythm bed stays continuous while section-specific office sounds remain independently controlled as SFX.
