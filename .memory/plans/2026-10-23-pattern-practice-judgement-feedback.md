# Plan: Pattern Practice Judgement Feedback

## Goal
Make a player's practice result immediately visible on the note that was judged. Every tap, hold, and burst note should flash its PERFECT, GOOD, or MISS grade and enlarge briefly for about 350 ms, while retaining the current lane, key, judgement text, and timing error feedback.
