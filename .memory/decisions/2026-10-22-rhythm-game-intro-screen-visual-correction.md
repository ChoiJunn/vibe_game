# Decisions: Rhythm Game Intro Screen Visual Correction

- Date: 2026-10-22
- Status: Confirmed

## D01. 적용 화면과 작업 기준
- **Chosen**: 첨부 이미지에 해당하는 공개 홈(`/`)을 현재 저장소 코드에서 다시 개선한다.
- **Rationale**: 첨부 이미지는 로그인 전 게임 시작 화면이다. 저장소의 기존 홈 작업은 완료로 표시돼 있지만, 사용자가 확인한 화면은 캐릭터·모션·가독성 측면에서 요구를 충족하지 못한다.

## D02. 화면 밀도와 글자 가독성
- **Chosen**: 게임 스테이지를 화면 대부분에 배치하고 바깥의 빈 공간을 줄인다. 제목, 안내, 시작 버튼이 서로 겹치지 않도록 시각적 계층을 정리하고 배경과 충분한 대비를 확보한다.
- **Rationale**: 사용자는 현재 글자가 읽히지 않고 여백이 과도하다고 보고했다. 첫 진입에서 게임 이름과 시작 동작이 즉시 읽혀야 한다.

## D03. 캐릭터와 장식
- **Chosen**: 기존 주인공과 모카 이미지를 스테이지 안에서 눈에 띄게 표시한다. 홈 화면의 양쪽 원형 장식은 제거한다.
- **Rationale**: 기존 캐릭터·마스코트 이미지가 이미 저장소에 있지만 첨부 화면에는 보이지 않는다. 사용자가 불필요하다고 지정한 모서리 원형 장식은 화면의 게임 분위기와 무관하다.

## D04. 모션 동작
- **Chosen**: 기존 장식용 미리보기 구조를 유지하면서 캐릭터 동작과 레인을 따라 움직이는 노트가 정지 화면에서도 알아보기 쉬운 속도와 크기로 반복되게 한다. 실제 게임 플레이와 세션 생성은 시작 전 자동 실행하지 않으며 `prefers-reduced-motion` 설정은 계속 존중한다.
- **Rationale**: 기존 계획 D02/D07은 장식용 애니메이션 미리보기와 이동 노트를 선택했다. 사용자의 최신 피드백은 구현된 모션이 화면에서 인지되지 않는 문제를 해결해 달라는 뜻으로 해석한다.

## D05. 인증 및 게임 동작 경계
- **Chosen**: Entra 로그인과 시작 버튼의 기존 동작을 보존하고, 인증·게임 세션·데이터 저장 로직은 이번 시각 개선 범위에서 바꾸지 않는다.
- **Rationale**: 요청은 홈 화면의 표현과 배치에 관한 것이며, 시작 흐름이나 저장 동작을 변경할 필요는 없다.

## 검증 범위 참고
- 현재 로컬 `localhost:3000`에서는 캐릭터 이미지가 로드되고 노트·캐릭터의 CSS 애니메이션이 실행되는 것을 확인했다.
- 저장소 문서에 기록된 Azure 공개 주소는 이번 환경에서 브라우저 요청 시간 초과로 확인하지 못했다. 구현과 렌더 검증은 로컬 저장소를 기준으로 진행하고, 배포 화면 반영 여부는 Azure 접근이 가능할 때 별도로 확인한다.
